## 1. Supplementary Table S1 のファイル形式

Springer / Graefe の Supplementary Information（SI）指針に従い、テキスト系 SI は長期保存に適した **PDF** で再提出いたします（`.doc`/`.ppt` は推奨されません）。

- 再提出ファイル名: **`ESM_1.pdf`**
- ファイル内タイトル: **Supplementary Table S1**（規則ベース形態分類および Standardized Caliber Uniformity Score のカットポイント表）
- 第2 SI（専門家–アルゴリズム一致の混同行列）: **`ESM_2.pdf`**
- 本文では Online Resource として言及するよう修正済みです（Online Resource 1 = S1、Online Resource 2 = 専門家一致）

なお、SI 内の **図** は本文図と別番号とする規則がありますが、本件 S1 は **表（table）** であり、`Supplementary Table S1` の命名が適切です。

## 2. Competing Interest（投稿システム）

投稿システム（submission interface）の Competing Interest 欄を、以下の文言に更新いたします（**著者側でオンライン入力を実施**）。

```
Y. Yanagi - Consultant/Speaker for Astellas Pharmaceutical, Bayer Yakuhin Ltd, Roche/Chugai Pharmaceutical Co., Ltd., Novartis Pharma K.K., Boehringer Ingelheim Co., Ltd., Santen Pharmaceutical Co., Ltd., Senju Pharmaceutical Co.
```

原稿本文の Conflict of Interest / Disclosures セクションは、上記と **既に一致** していることを確認済みです（本文の変更は不要です）。

## 3. Figure 1 のラベリング

提出済みマルチデバイス分割例の図ファイル名が `Figure.tiff` / `Figure.png` となっており、図番号がファイル名に明示されていませんでした。内容・パネル（A–C）・レジェンドはもともと **Figure 1** です。再提出用に **`Figure1.tiff`** / **`Figure1.png`** へリネームしました。

## 4. Table 5 の引用位置

**Table 5 は存在します**（形態パターン → morphology-derived interpretive category の対応表。Tables ファイル内、Tables 1–5）。初回改訂稿の本文では Table 4 までの言及にとどまり、Table 5 の in-text 引用が欠落していました。

対応: Results「Rule-Based Morphological Categorization…」節の Table 4 段落末に、次の一文を追加しました。

> Morphology-derived interpretive mapping of these five operational subtypes is summarized in Table 5.

配置は Table 4（亜型分布）の直後が適切です。Table 5 を新規に作成したものではありません。
