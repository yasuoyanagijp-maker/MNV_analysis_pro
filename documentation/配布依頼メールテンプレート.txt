■ ご利用方法（解析モードの選択）

起動後、ダッシュボードの「Analysis Type」から解析モードを選択してください。
本ソフトは、もともと黄斑新生血管（MNV）の定量的解析を目的として開発・運用しており、通常は「MNV Analysis」をお使いいただく想定です。VD解析や統合解析は、研究目的に応じて選択してください。

・MNV Analysis（通常の用途）
  黄斑新生血管（MNV）の形態・構造解析です。ROI（関心領域）を指定し、MNV面積、血管密度、パターン分類、Complexity / Stability スコア等を出力します。加齢黄斑変性症のMNV評価が主な用途です。

・VD Analysis — single SCP/DCP
  網膜血管密度（VD）の解析です。浅層（SCP）・深層（DCP）の OCT-A 画像ペア（既定：末尾が 1.tif / 2.tif）から、FAZ、扇形領域別の血管密度等を定量します。MNV解析ではなく、網膜血管解析を行いたい場合に選択してください。

・Integrated Analysis (VD + MNV)
  同一フォルダ内の画像に対し、VD解析（SCP/DCPペア）の後、MNV解析（ROI指定）を続けて行う統合モードです。VDとMNVの両方を一括で評価したい場合にご利用ください。

※画像ファイル名の規則（_1 / _2 / _3 等）や詳しい操作手順は、同梱のマニュアルをご参照ください。

■ 画像の選択方法（重要）

解析を開始する際は、画像ファイルを1枚ずつ選ぶのではなく、フォルダ単位で指定してください。

1. 新しいフォルダを作成してください。
2. そのフォルダの中に、解析したい画像を入れてください。
3. アプリの画像選択画面で、個別のファイルではなく上記フォルダを選択し、「Confirm Selection」を押してください。

※ ImageJ 等での画像変換は通常不要です。OCT-A 画像をそのままご利用いただけます。

■ Mac版 — インストール方法（通常）
================================================================================

1. 添付の ZIPファイルをダブルクリックして展開してください。
2. 展開されたフォルダ内の「インストール.command」を、右クリック（または Control + クリック）→「開く」で実行してください。
   ※初回は macOS のセキュリティにより、ダブルクリックだけでは開けない場合があります。
3. 画面の案内に従うと、Applications フォルダへ自動インストールされ、完了後にアプリが起動します。
4. 次回以降は、Launchpad または Applications フォルダの「ARIAKE_OCTA」から起動できます。

■ うまくインストールできない場合（ターミナルでの手順）

上記の方法でインストールできない場合は、以下の手順をお試しください。

1. ターミナルを起動します（Launchpad →「ターミナル」）。
2. 展開したフォルダに移動します（フォルダをターミナルウィンドウへドラッグ＆ドロップするとパスが入力されます）。

cd （展開したフォルダのパス）

3. 以下のコマンドを順に入力して Enter を押してください。

xattr -cr ARIAKE_OCTA.app
cp -r ARIAKE_OCTA.app /Applications/
open /Applications/ARIAKE_OCTA.app

4. インストールが完了し、アプリが起動します。

補足：「インストール.command」自体が開けない場合は、先に以下を実行してから ./インストール.command をお試しください。

xattr -cr インストール.command
chmod +x インストール.command
./インストール.command

■ Windows版 — インストール方法
================================================================================

1. 添付の ZIPファイルを右クリック →「すべて展開」で展開してください。
2. 展開された「ARIAKE_OCTA」フォルダを開き、「ARIAKE_OCTA.exe」をダブルクリックして起動してください。
   ※「ARIAKE_OCTA.exe」と「_internal」フォルダは同じ階層にある必要があります。exe だけを別の場所へ移動しないでください。
3. 初回起動時に Windows Defender SmartScreen 等の警告が表示される場合があります。
   「詳細情報」→「実行」を選択して起動してください。
4. 次回以降も、同じ「ARIAKE_OCTA」フォルダ内の ARIAKE_OCTA.exe から起動できます。
   デスクトップにショートカットを作成していただいても構いません。

■ うまく起動できない場合

・ZIP を展開した「ARIAKE_OCTA」フォルダごと使用しているか確認してください。
・社内 PC ではセキュリティソフトや管理者権限により exe の実行が制限されている場合があります。
  その場合は IT 部門への exe 実行許可のご相談、またはお気軽にご連絡ください。
