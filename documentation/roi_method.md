# ARIAKE OCTA — ROI の指定方法

**対象:** 第1グレーダー・第2リーダー・最終読影者（施設／Team YY 共通）  
**画面:** Step 1: ROI selection（`/roi`）  
**日付:** 2026-08-21

MNV 解析では、定量の対象を **関心領域（ROI）マスク** として指定します。従来の **フリーハンドで取り囲む／Erase で削る** 操作に加え、アプリが同定した血管（着色画像）を手がかりに **余白だけを除く** 方法が使えます。第2読影でも第1のマスクは流用せず、**毎回この画面で独立して ROI を作ります。**

---

## 1. この画面で決まること

ROI マスクは、その後の血管検出・形態計測の **解析領域**です。緑の半透明が「残す領域」、その外側は解析しません。

| 操作 | ボタン名 | 役割 |
|------|----------|------|
| （任意）切り出し | **0. Crop Image** | 横長画像など、解析したい四角を切り出す |
| 手動で取り囲む | **1. Draw ROI（フリーハンド）** | MNV を含む領域をなぞって囲む |
| 手動で削る | **2. Erase Noise（長押し）** | 緑の内側の暗いノイズ・背景の隙間を除く |
| 血管同定を見る | **着色画像** | 黄＝血管、赤＝拡張。ROI の緑塗りは一時的に非表示 |
| 同定部位に合わせる | **余白trim** → **採用** | 着色のない余白だけを ROI から除く |
| やり直す | **Undo** / **Reset** | 直前に戻す／マスクを空にする |
| MNV なし | **Skip — MNV absent** | 形態計測せず、空マスクと「病変なし」を記録 |
| 次へ | **Confirm ROI & Proceed** | マスクを確定して解析へ（再解析時は **Confirm & Re-analyze**） |

推奨の流れは、**囲む →（必要なら Erase）→ 着色画像で血管を確認 → 余白trim を採用 → 足りない血管は Draw で足し、余計な背景は Erase で削る → Confirm** です。

---

## 2. 従来の手動操作

### 2.1 Crop Image（任意）

横に広い画像では、最初からこのモードが選ばれることがあります。

1. **0. Crop Image** を選ぶ。  
2. 解析したい範囲をドラッグで四角く囲む。  
3. **クロップ確定** を押す（内部で切り出し・拡大して ROI 画面をやり直します）。  
4. やり直すときは **元画像に戻す（クロップ取消）**。

通常の正方形に近い en face 像では、Crop は不要なことが多いです。

### 2.2 Draw ROI（フリーハンドで取り囲む）

1. **1. Draw ROI（フリーハンド）** を選ぶ（初期状態は多くの場合こちら）。  
2. 画像上でドラッグし、**MNV を含む領域をなぞって閉じる**。  
3. 指（マウス）を離すと、囲んだ内側が **緑の半透明**になります。  
4. 囲み終えると、自動的に **2. Erase Noise** へ切り替わります。  
5. 取りこぼした領域は、もう一度 Draw に戻って追加で囲めます（既存マスクに足されます）。

囲みが粗いと、病変の外側の背景や無関係な血管が ROI に入ります。後段の Erase と余白trim で削れます。

### 2.3 Erase Noise（長押しで削る）

1. **2. Erase Noise（長押し）** を選ぶ（Draw の直後は自動でこちら）。  
2. **緑で示した領域の内側**で、除きたい暗いノイズや背景の隙間の上を **長押し**する。  
3. 押し続けているあいだ、除去の範囲が徐々に広がります。離すと、その時点の削りがマスクに反映されます。  
4. 消しすぎたら **Undo**（直前の状態に戻る）。最初からやり直すときは **Reset**（マスクが空になります。着色状態もクリアされます）。

Erase は「黒い隙間をまとめて除く」ための操作です。細い血管そのものを消したい場合は、長押ししすぎないよう注意してください。

### 2.4 Undo / Reset

| ボタン | 動作 |
|--------|------|
| **Undo** | 直前の描画・Erase・（採用済みの）trim を 1 段階戻す |
| **Reset** | マスクを空にし、着色画像・trim の状態も破棄する |

## 3. 血管の同定部位を選ぶ方法（着色画像 + 余白trim）

手動の囲みだけでは、病変の周りに **血管でない余白**が残りやすいです。アプリは解析と同じ系統の血管検出で **着色画像**を作り、その同定部位だけを ROI に残す **余白trim** を用意しています。

**できること:** 着色されていない余白を ROI から除く。  
**手動のまま行うこと:** 背景の無関係な血管の削除、切り落としてしまった病変血管の追加。

### 3.1 着色画像（血管同定の表示）

前提: **先に Draw ROI で領域を囲んでおく**（ROI が空のときは着色できません）。

1. **着色画像** を押す。作成中は「着色中...」と表示されます。  
2. キャンバスがカラー表示に切り替わります。

| 色 | 意味 |
|----|------|
| **黄** | 同定された血管 |
| **赤** | 拡張（細動脈化に相当する成分） |
| **グレー系** | 背景（元画像の輝度） |

このあいだ、ROI の **緑の半透明は非表示**です。緑が黄・赤の血管を覆い隠さないようにするためです。マスク自体は変わっていません。

3. 黄・赤が病変血管に沿っているか確認する。  
4. Draw / Erase を再開すると、緑の ROI 表示が戻ります。

着色は解析パイプラインと同じ幅ゲートの血管検出に基づきます。表示は確認用で、この時点ではまだ ROI は切り詰められません。

### 3.2 余白trim（同定部位だけを残す）

1. 着色画像が表示されている状態で **余白trim** を押す。  
2. プレビューになります。

| 色 | 意味 |
|----|------|
| **緑** | 残す領域（着色＝血管同定と、いまの ROI が重なる部分） |
| **赤** | 除く余白（ROI 内だが着色がない部分） |

3. 内容を見て **採用** または **取り消す**。

| ボタン | 動作 |
|--------|------|
| **採用** | 緑の領域だけが新しい ROI になる。必要ならそのあと手動で削る／足す |
| **取り消す** | プレビューを破棄し、trim 前のマスクのまま |

画面の注記どおり、**着色のない余白だけ**が除かれます。背景に乗っている別の血管（黄・赤として同定されているもの）は trim では消えません。それらは **Erase** で手動削除します。逆に、病変なのに着色から外れた血管は **Draw ROI** で囲い直して追加します。

着色と ROI の重なりがゼロのときは trim できません。囲みを広げてから、もう一度着色画像を作り直してください。

### 3.3 着色のあとに手動編集するとき

- Draw / Erase を選ぶと緑の ROI が再表示されます。  
- マスクを描き直したら、必要に応じて **着色画像** を押し直して確認します。  
- **Reset** すると着色も消えます。最初から囲み直してください。

## 4. 推奨手順（従来 + 血管同定）

施設読影でも Team YY の第2読影でも、同じ手順です。

1. （横長なら）**Crop** で解析枠を切り出す。  
2. **Draw ROI** で MNV を少し余裕をもって取り囲む。  
3. 明らかな黒い背景・器具影があれば **Erase** で落とす。  
4. **着色画像** で黄・赤の血管同定を見る。  
5. 余白が目立つときは **余白trim → 採用**。  
6. 背景血管の取り残しは **Erase**、切り落とした病変血管は **Draw** で修正する。  
7. 緑の領域で問題なければ **Confirm ROI & Proceed**（再解析時は **Confirm & Re-analyze**）。  
8. 次画面の MNV ウィザードでプレビューを確認し、**Confirm & Start Analysis** へ進む。

**ROI が空のままでは Confirm できません。**

バッチ解析では、症例ごとにこの画面が繰り返されます。結果側の QC では **OK — next image** / **Redo ROI** / **Stop Here** が使えます。

---

## 5. MNV が見えないとき（Skip）

病変がはっきりしない症例は、無理に ROI を作らず **Skip — MNV absent** を使います。

- 形態計測は実行しません。  
- 学習用に **空（全黒）マスク** と **`mnv_present=false`** を残します。  
- CSV では数値は空、`MNV present=0`、`Quality of analysis=N/A` です（Fail ではありません。QC と病変有無は別フィールドです）。

## 6. よくある誤解

| 誤解 | 実際 |
|------|------|
| 着色画像を押せば ROI が自動確定する | 表示だけの確認。切り詰めは **余白trim → 採用** |
| 余白trim で背景の別血管も消える | 消えない。着色されている血管は残る。**Erase** で除く |
| 第2読影は第1の ROI を引き継ぐ | **引き継がない。** 毎回この画面で独立して指定する |
| 緑が見えないのはマスクが消えた | 着色表示中は緑を隠しているだけ。Draw / Erase に戻すと再表示される |
| Skip は解析失敗 | 病変なしの記録。Fail ではない |

Uniformity が結果で厳密に **25.0** と出た場合は、ROI を見直して再解析を検討してください（USER_MANUAL §10.1）。
