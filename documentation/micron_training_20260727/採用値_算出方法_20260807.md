# 採用値の算出方法（2026-08-07）

## 一般的な方法
二重独立読影の定量値について、臨床画像評価で広く用いる次のルールを適用した。

1. **両読者の値がそろっているとき**  
   - **Relative Percent Difference (RPD)**  
     `RPD = |A − B| / ((|A| + |B|) / 2) × 100`  
   - **RPD ≤ 10%** → **採用値 = 算術平均 (A+B)/2**  
   - **RPD > 10%** → **再検査扱い → 採用値 = NA**

2. **片方欠損** → 採用値 = NA（MISSING）

3. **Caliber / Maturity**  
   - 正式評価は **U2** 列（`Caliber Uniformity Score (U2)` / `Maturity Index (U2)`）  
   - 旧 PCA 列も同じ RPD ルールで併記
