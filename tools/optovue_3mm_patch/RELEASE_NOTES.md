## Optovue 3mm パッチ

インストール済みのアプリに、起動ウィザードの **3 mm (Optovue)** と **3 mm (Zeiss HD)** を足します。アプリ一式の入れ替えではありません。

| ZIP | 適用先 |
|-----|--------|
| `ARIAKE_OCTA_optovue_3mm_patch_mac_apple_silicon.zip` | Mac v1.2.4 Apple Silicon（`ARIAKE_OCTA_mac.zip`） |
| `ARIAKE_OCTA_optovue_3mm_patch_mac_intel.zip` | Mac v1.2.4 Intel（`ARIAKE_OCTA_macOS_Intel_v1.2.4.zip`） |
| `ARIAKE_OCTA_optovue_3mm_patch_windows.zip` | Windows v1.2.3（`ARIAKE_OCTA.zip`） |

画素のスケールはどちらも 3.0 mm です。Optovue は Optovue 3mm の Complexity と形態分類を使います。Zeiss HD、数値の 3.0、手入力の 3 mm は従来の CIRRUS HD 3×3 のままです。Caliber Uniformity、病態分類、Caliber U2 も Zeiss HD 3mm の基準のままです。

各 ZIP の `パッチの説明.txt` の手順で適用してください。Mac は適用後にアドホック再署名します。
